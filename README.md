# StudySmart — Smart Study & Exam Preparation Platform

StudySmart is a full-stack web application designed to help students prepare for exams with organized study notes, previous year question papers, and revision tracking.

## Features

- **Study Notes:** Access and manage subject-wise study notes.
- **Previous Year Papers:** Find exam papers for subjects such as Java, DBMS, Computer Networks, HTML, and JavaScript.
- **Revision Section:** Track revision topics and completed tasks.
- **Search and Filter:** Find notes by keyword or subject.
- **Notes Management:** Add, edit, and delete notes.

## Tech Stack

- Frontend: React.js, JavaScript, HTML, CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Tools: Git, GitHub, Vite

## Installation

1. Clone the repository:

   `git clone YOUR_REPOSITORY_URL`

2. Open the project folder:

   `cd smart-study-platform`

3. Install frontend dependencies:

   `npm install`

4. Install backend dependencies:

   Navigate to the backend folder and run `npm install`.

5. Configure the backend `.env` file with your MongoDB connection string and required environment variables.

6. Start the backend and frontend using the scripts defined in their respective `package.json` files.

## Security

Never commit `.env` files, database credentials, or other secrets to GitHub.
